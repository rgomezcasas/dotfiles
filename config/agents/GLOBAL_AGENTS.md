# Rules

## Language

- Reply in the same language the user used (if it's Spanish, use Spain Spanish)
- Write all code, comments, docs, commits, and tests in English

## Code

- Write self-documenting code, **never** add explanatory comments
- Use inclusive terms: allowlist/blocklist, primary/replica

## Git and GitHub

- **Never** include your session URL in commit messages
- When you commit, follow this format for the Coauthor (always include it unless I say otherwise): `Co-Authored-By: {tool} - {model.name} {model.version} <{tooling_email}>`
- Open PRs with `gh pr create --assignee @me` so they're assigned to me

## Tools

- To copy files or directories, use macOS native `/bin/cp -c` (APFS clone) instead of the `cp` in `PATH` (GNU coreutils)
- If I send you a Twitter link, and you can't access it, replace x.com with https://api.fxtwitter.com/USER/status/ID so you can open it.

# Context

- I often dictate messages, so the transcript may come out a bit strange. If you see words that don't fit, that's probably why. Try to understand what I mean from the context.
